# 과제 5 · AI A → AI B 인수인계

## 1. 목표
과제 4 서울 기온 정보판에 ‘일별 기록 CSV 내려받기’ 한 기능을 완성한다. 최초 요청과 변경 불가 검사 10개는 t05/frozen.json에 있다. AI별 30분, 사용자 요청 10회. 첫 구현 요청부터 종료까지 센다. 내부 도구 호출은 제외한다. B는 A와 다른 서비스 또는 모델의 무료 AI를 실제 사용한다.

## 2. 현재 상태
원본은 사용자가 제공한 ALEPH_04_source.zip. 과제 5 별도 복사본이며 원본 사이트 연결 파일은 제거했다. A 시작 버전은 f036db59f208bd9255690af5688762728503615e, A 종료 코드 버전은 316477ee6402a6a7406d3aaac096e730adf49f2a (태그 A_END)이다. 문서·로그 저장 커밋은 이 코드 버전 뒤에 추가되며 기능 코드는 같다. lib/csv.mjs와 타입 선언은 완성. 화면 버튼은 미구현. A 2회 검사 모두 10/10, 실패 회차 0, 사용자 요청 1회, 작업 138.9초. frozen.json SHA-256: c68eda2951580593dcd60e9f5647730ce2411d19753e0cb889a6fad49685ee75.

## 3. 실행 명령
필요 버전: Node.js 22.13 이상, Git. 전체 UI는 package.json의 pnpm 11.25.0을 따른다.
저장소 폴더에서 `node t05/checks.mjs` 실행. 이 검사는 추가 설치·환경값·API·DB 없이 된다.
새 폴더 재현: `git clone <공개_과제5_저장소_URL> ALEPH_05_fresh` → `cd ALEPH_05_fresh` → `node t05/checks.mjs`.
전체 UI 준비: `npm run install:ci` → `npm run dev`. 전체 실제 조회는 원본 Cloudflare D1 구성이 필요하다. CSV 검사에는 필요 없다. 화면 확인은 합성 실패 검사에서 D1/D2를 재생해 기록을 만든다. pnpm/런타임 설치가 막히면 누락/환경 차이를 로그에 남긴다.

## 4. 통과 검사
CSV-01~CSV-10 전부 PASS. t05/A-results-01.json 및 A-results-02-fresh.json. 새 clone에서 두 번째 실행 성공. 테스트는 CSV 내용/파일명/빈 기록 반환을 확인하며 브라우저 다운로드 버튼은 아직 확인하지 않았다.

## 5. 남은 문제
app/page.tsx에 CSV 다운로드 버튼과 안내가 없다. B 시작/완료, 사용량, 화면 다운로드 확인, 공개 비교 보고서, 공개 URL 검증은 미완료. A가 이를 완료했다고 기록하면 안 된다.

## 6. 다음 행동
B 시작 시각·시작 git SHA 기록. lib/csv.mjs의 exportCsv(state.rows, mode)를 호출하는 버튼을 일별 기록 패널에 연결한다. content가 null이면 message를 표시하고 파일을 만들지 않는다. 정상 결과는 UTF-8 text/csv Blob, 임시 링크 download, object URL 해제 방식으로 저장한다. 실제/합성 모드의 현재 state.rows만 사용한다. 같은 검사 10개 실행마다 JSON 결과 저장, FAIL 회차 수 계산. 브라우저 다운로드와 빈 기록 안내 확인 후 B 종료 시각·SHA·사용자 요청 수 기록. 모델 이름을 가린 공개 비교 보고서에는 A/B의 순차 작업이며 동일 출발점의 경쟁 비교가 아님을 명시한다. 재작업량은 수기 입력하지 않는다. 인수인계 누락은 없으면 없음, 있으면 원본을 보존하고 수정본을 별도 기록한다.

## 7. 건드리지 말 것
t05/frozen.json, t05/checks.mjs의 검사·기대값, public/t04 공식 자료, 원본 저장·조회·실패 처리, 과제 4 배포를 바꾸지 않는다. 대화 전문을 요구하거나 공개하지 않는다. 개인정보/비밀값을 넣지 않는다. B에게 이 저장소와 이 문서만 주고 문서 원본 SHA-256을 대조한다.
